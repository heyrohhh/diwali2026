# Deepotsav — Diwali Interactive Website v2.0

Responsive vanilla HTML/CSS/JS celebration website.

## Features
- Mobile and desktop responsive layout
- Animated CSS diya, rotating rangoli and ambient glow
- Canvas fireworks on celebration and greeting creation
- Personalised greeting generator, signed **With warm wishes, Rohit**
- Copy greeting and WhatsApp share
- URL greeting support: `?to=FriendName`
- Optional synthesized bell-like notes (starts after user interaction)

## Run
Open `index.html`, or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

No build tools required. Google Fonts need an internet connection; local fallback fonts are used otherwise.
